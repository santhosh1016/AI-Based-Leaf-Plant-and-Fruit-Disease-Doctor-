# Initial Requirements

## Functional Requirements
- User should be able to capture or upload plant images
- System should process image and detect disease
- Result should be displayed clearly to user
- Application should store history of results

## Non-Functional Requirements
- Application should be easy to use (user-friendly)
- System should respond quickly
- Output should be clear and understandable
- Application should work smoothly on Android devices

## Tools and Technologies
- Android Studio (Mobile App Development)
- Google Colab (Model development)
- Kaggle (Dataset)
- TensorFlow Lite (Model integration)
- GitHub (Version control)

These requirements were identified during the initial planning phase of the project.
