# Dataset Selection

## Week 2 Focus
In Week 2, we discussed which dataset can be used for training the plant disease detection model.

## Dataset Source
We planned to use a plant disease image dataset from Kaggle.

## Reason for Selecting Kaggle Dataset
- It contains plant disease images
- Images are already arranged class-wise
- Suitable for image classification
- Easy to use with Google Colab

## Dataset Requirements
The dataset should contain:
- Healthy plant images
- Diseased plant images
- Clear class labels
- Enough images for training and testing

## Planned Use
The dataset will be downloaded using Kaggle API in Google Colab. After downloading, images will be resized, normalized, and used for training the AI model.
