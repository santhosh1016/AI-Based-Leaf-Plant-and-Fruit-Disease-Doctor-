
## Testing Areas
The main areas planned for testing are:

- Dataset validation
- Image preprocessing validation
- AI model output checking
- Android app UI testing
- API response checking
- Result display validation

## Planned Test Cases
| Test Area | What to Check | Expected Result |
|---|---|---|
| Dataset | Folder and labels | Correct class-wise structure |
| Preprocessing | Image resizing | Images should resize properly |
| Model | Prediction output | Disease class should be predicted |
| Android App | Navigation | Screens should open smoothly |
| API | Response format | Response should be clear |
| Result Screen | Output display | Result should be readable |

## Purpose
This planning helps ensure that testing is not done randomly. It gives a clear direction for validation in later weeks.
