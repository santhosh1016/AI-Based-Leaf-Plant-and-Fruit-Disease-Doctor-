# System Architecture

## Project Name
AI Based Leaf, Plant and Fruit Disease Doctor

## Week 2 Focus
In Week 2, we planned the overall system architecture and decided how different parts of the project will connect with each other.

## System Flow
The basic system flow is:

User → Android App → Backend/API → AI Model → Result → Android App

## Explanation
The user will upload or capture an image of a leaf, plant, or fruit using the Android application. The image will be sent for processing, and the AI model will predict the disease. After prediction, the result will be displayed to the user in the application.

## Main Components
- Android Application
- Image Input Module
- AI Model
- Backend/API Communication
- Result Display
- History Module

## Purpose
This architecture helps us understand how each module will work together and reduces confusion during development.
