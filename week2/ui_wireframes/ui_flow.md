# UI Flow Planning

## Week 2 Focus
In Week 2, the basic UI flow of the Android application was planned.

## App Name
AI Based Leaf, Plant and Fruit Disease Doctor

## Planned UI Flow

Splash Screen  
→ Intro Screens  
→ Login / Register  
→ Home Screen  
→ Camera / Upload Image  
→ Result Screen  
→ Disease Information  
→ History Screen

## Explanation
The app will start with a splash screen and intro screens. After that, the user can login or register. From the home screen, the user can upload or capture an image. After processing, the disease result will be shown clearly.

## UI Design Goals
- Simple design
- Easy navigation
- Clear buttons
- Readable text
- User-friendly result display

## Reason
Since the app is mainly for farmers and general users, the UI should be simple and not confusing.
