# Integration Plan (Week 3)

## Week 3 Focus
In Week 3, planning for integration of all modules was done.

## Modules to Integrate
- Android Application
- Backend API
- AI Model (TFLite)

## Planned Integration Flow
1. App captures image
2. Image is sent to backend
3. Backend passes data to AI model
4. Model generates prediction
5. Result is returned to app
6. App displays output

## Challenges Identified
- Data format mismatch
- Model output handling
- API response delay

## Solution Approach
- Standardize data format
- Keep API simple
- Test integration step by step
