## Final App Flow

Splash Screen  
→ Intro Slider  
→ Login / Register  
→ Home Screen  
→ Camera / Upload Image  
→ Result Screen  
→ Disease Information / Cure Suggestion  
→ History Screen  
→ History Detail Screen

## Screen Purpose

### Splash Screen
Provides the first entry point of the application and gives the app a professional start.

### Intro Slider
Explains the basic purpose of the application to new users.

### Login / Register
Allows users to access the application with their details.

### Home Screen
Acts as the main navigation screen.

### Camera / Upload Screen
Allows the user to capture or select a plant image.

### Result Screen
Displays the predicted disease result.

### Disease Information Screen
Provides details and possible cure suggestions.

### History Screen
Allows users to view previous disease detection results.
